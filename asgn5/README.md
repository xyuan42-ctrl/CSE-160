# Assignment 5 - Three.js Cherry Blossom Village


### index.html
Main webpage. It creates the canvas, imports Three.js using an import map, shows the instructions/score panel, and loads `main.js`.

### main.js
Main Three.js scene file. It sets up the renderer, perspective camera, OrbitControls, WASD movement, lights, skybox, textured ground, village objects, cherry blossom trees, animated falling petals, animated coins, and the loaded textured `.gltf` model.

### style.css
Basic page and overlay styling.

### assets/textures/
Contains simple generated textures used by the ground, houses, roofs, and rocks.

### assets/skybox/
Contains the six cube-map images used for the textured skybox.

### assets/models/rocket.gltf
A small starter textured 3D model loaded with `GLTFLoader`. You may replace it with a better `.glb` or `.gltf` model later.
